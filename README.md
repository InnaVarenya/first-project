# Банковские данные клиентов: проект для курса "Python-разработчик" от SkyPro

## Описание проекта
Проект предназначен для обработки и управления банковскими данными клиентов.  
Основной функционал:
- Маскировка номеров карт и счетов клиентов.
- Сортировка данных по дате выполнения операций.
- Вывод транзакций пользователя с фильтрацией по валюте операции.
- Приём списка транзакций и поочерёдный вывод описаний операций.
- Генерация номеров банковских карт в формате ХХХХ ХХХХ ХХХХ ХХХХ (от 0000 0000 0000 0001 до 9999 9999 9999 9999).
- Декоратор для логирования начала, конца выполнения функций и возможных ошибок.
- Работа с JSON-файлами транзакций: загрузка данных из файла.
- Обращение к внешнему API для получения курса валют и конвертация сумм транзакций из USD и EUR в RUB.

## Ключевые возможности
- Гибкое управление банковскими данными.
- Поддержка фильтрации и форматирования вывода.
- Надёжное логирование с помощью собственного декоратора.
- Высокая степень тестового покрытия (98%).

## Тестирование
- На каждый модуль написаны unit-тесты.
- Для взаимодействий с внешними API используются мок-объекты (`unittest.mock`, `pytest-mock`).
- Проверяется корректная обработка ошибок и граничных случаев.
- Используется `pytest` с генерацией отчётов по покрытию кода.
- Покрытие тестами составляет 98%, что подтверждается отчётами и CI-системой.
