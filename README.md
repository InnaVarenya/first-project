# Проект
## Описание проекта
Данный проект создан при прохождении курса "Python-разработчик" от SkyPro.
Этот проект направлен на обработку банковских данных клиентов.
Например, маскировка номера карты и номера счета клиента, сортировка данных по дате выполнения.
Функциональность проекта также позволяет выводить транзакции пользователя с заданной валютой операции, принимать список транзакций и возвращать
описание каждой операции по очереди и генерировать номера банковских карт в формате ХХХХ ХХХХ ХХХХ ХХХХ в диапазоне
от 0000 0000 0000 0001 до 9999 9999 9999 9999.
Проект включает в себя декоратор, который автоматически логирует начало и конец выполнения функции, а также ее результаты или возникшие ошибки.

## Тестирование проекта
На каждый модуль проекта разработан тест. Функциональный код покрыт тестами на 95%.
