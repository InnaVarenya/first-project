# Проект
## Описание проекта
Данный проект создан при прохождении курса "Python-разработчик" от SkyPro.
Этот проект направлен на обработку банковских данных клиентов.
Например, маскировка номера карты и номера счета клиента, сортировка данных по дате выполнения.

## Тестирование проекта
На каждый модуль проекта разработан тест. Функциональный код покрыт тестами на 100%.
